## 2. Advanced 要不要上左轮？

**结论（草案拍板）：Advanced 闯关默认不上左轮。**

| | 上左轮 | 不上（推荐） |
| --- | -------- | ---------------- |
| 优点 | 高难统一有收官表演 | 保住「汇总推理推完最后一格」的核心乐趣 |
| 缺点 | 入场要揭晓哪三格为绿，等于残局送 Easy 列示；与 Advanced 哲学冲突 | 戏剧性留给噩梦 / 练习开关 |

补充：

- 自定义试炼可单独打开「左轮彩蛋」，与 Advanced 提示方式组合试用。  
- 若以后要在 Advanced 开：仅作**设置项 / 隐藏开关**，默认关，且同样适用「打空即负」。

---

## 3. 左轮触发条件（严格）

仅「三锁一悬」（`exact === 3` 且只剩一格未定色）时触发。
